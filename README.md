# FlexGov

**Adaptive governance security for DAOs — deterrence, not fortification.**

FlexGov is a governance-observability and adaptive-safeguards framework. It analyses who determined a governance outcome, measures manipulation-risk signals, compares results across voting mechanisms (1T1V, QV, 1W1V, Gini-normed), and applies a community's pre-authorised escalation policy — with the goal of making governance attacks cost more than they pay.

> The BonkDAO attacker spent $4.4M to take $20M. FlexGov exists to invert that ratio.
