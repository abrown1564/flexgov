# AGENTS.md — working rules for AI assistants on this repo

1. **Comment often.** Every non-obvious function, threshold, and design
   decision gets a plain-language comment explaining *why*, not just what.
2. **Commit frequently.** Small commits, small diffs, clear messages. The
   commit trail is part of the project's story.
3. **No edits without the owner's go-ahead.** Propose first, wait for
   approval, then act. This includes commits, renames, and deletions.
4. **Plain language.** Avoid acronyms and jargon when talking to the owner;
   when unavoidable, expand them on first use.
5. **Never paste in old code.** New code is written fresh in this repo.
   Prior research informs design; it does not get copied in.
6. **Advisory framing.** The engine detects, measures, and recommends. It
   never claims to have "prevented" anything — detection + time + evidence.
